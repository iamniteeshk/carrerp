# Murahari_M profile pack (production layout)

Canonical v1 layout::

    profiles/Murahari_M/<Specialization>/profile.yaml
    profiles/Murahari_M/<Specialization>/<Resume>.pdf

Copy into the live data root and replace placeholder PDFs with real resumes.
Set `profiles.default: General` (or another specialization name) in config.yaml.

Optional companion files per specialization:
keywords.yaml, preferred_locations.yaml, screening_answers.yaml
